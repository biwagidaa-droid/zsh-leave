## خواندن وضعیت‌ها

- **پیاده‌سازی‌شده و آزموده‌شده:** شواهد آزمون خودکار/Build در وضعیت فعلی ثبت شده است؛ این برچسب، گواهی تولید یا پوشش کامل نیست.
- **پیاده‌سازی‌شده، آزمون‌نشده:** منطق/مسیر در کد وجود دارد، اما آزمون متناظر در این اجرا یا در بستر لازم تأیید نشده است.
- **نیمه‌پیاده‌سازی‌شده:** بخشی از رابط یا سرویس وجود دارد اما اتصال/پوشش کامل نیست.
- **پیاده‌سازی‌نشده:** مسیر/زمان‌بند/رابطی در کد فعلی پیدا نشد.
- **مسدود:** نیازمند تنظیمات زیرساخت، داده واقعی یا تصمیم سازمانی است.

این بسته، راهنمای بهره‌برداری تأییدشده برای سامانه عملیاتی نیست؛ پیش از استفاده تولیدی، چک‌لیست سند ۰۹ باید با شواهد محیط واقعی تکمیل شود.
