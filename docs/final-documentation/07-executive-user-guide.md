# راهنمای گزارش‌خوان ارشد (Executive)

`exec` نقشی با محدوده سازمانی تجمیعی است و به‌تنهایی دسترسی مشاهده درخواست فردی یا اطلاعات هویتی کارکنان نمی‌دهد. مجوز واقعی در API بررسی می‌شود؛ سند [ماتریس نقش‌ها](08-role-permission-matrix.md) منبع دامنه است.

## ورود و مشاهده گزارش

پس از تخصیص فعال نقش `exec` توسط مدیر سامانه، وارد شوید. route فرانت‌اند `/reports` برای `hr` و `exec` و route `/balances` برای `exec` قابل مشاهده است. صفحه گزارش از انواع گزارش API استفاده می‌کند. صفحه `/balances` برای دارنده نقش Executive که EmployeeProfile ندارد قابل استفاده نیست: API برای خواندن balance به EmployeeProfile نیاز دارد و نقش `exec` به‌تنهایی employee queryset را گسترش نمی‌دهد؛ بنابراین روی آن برای گزارش تجمیعی Executive حساب نکنید:

- `absences`: شمار رخدادهای درخواست‌های Approved به تفکیک برچسب نوع؛
- `balances`: شمار کارمندان دارای entitlement (گزارش توازن تجمیعی، نه فهرست تکی)؛
- `trends`: تجمیع بر اساس ماه تاریخ شروع؛
- `process-health`: شمار درخواست‌ها بر اساس وضعیت؛
- `bradford`: endpoint عمومی فعلی سری خالی و یادداشت ارجاع به صفحه HR می‌دهد.

تمام خروجی‌های گزارش وابسته به محدوده RoleAssignment و `privacy.min_group_size` هستند. اگر گروه از حداقل اندازه کمتر باشد، سری/کل گزارش خالی یا با یادداشت privacy پاسخ داده می‌شود. از کنار هم گذاشتن خروجی‌ها برای بازشناسایی کارکنان خودداری کنید.

## چیزهایی که فعلاً وجود ندارند

در UI صفحه executive dashboard، KPI سازمانی مستقل، مقایسه چند شرکت، تقویم پوشش سازمانی، صف pending approvals یا trendهای cross-company به‌صورت محصول نهایی پیدا نشد. صفحه تقویم org فقط به HR مجاز است. API گزارش‌ها چند نوع aggregate دارد؛ این با داشبورد جامع مدیران یا Export برابر نیست. endpoint عمومی bradford هم تحلیل صفحه HR را برنمی‌گرداند.

## محرمانگی و خطا

نقش `exec` نمی‌تواند شناسه درخواست فردی را بخواند یا برای کارمند تصمیم بگیرد؛ API باید 404/403 برگرداند. UI نمایش مانده ممکن است صفحه مشترک باشد، اما مجوز backend تعیین‌کننده است؛ دسترسی فردی اضافه را گزارش کنید. برای 404، 403، گروه پنهان یا خروجی غیرمنتظره، محدوده تخصیص و ضابطه privacy را از مالک داده بخواهید، نه اینکه از URLهای دیگر داده استخراج کنید.
